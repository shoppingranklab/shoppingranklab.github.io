# 닥터올로지 (Dr.Ology) 브랜드 스토어

가정의학과 전문의가 직접 운영하는 브랜드 Dr.Ology의 정적 브랜드 스토어입니다.
제품이 계속 추가되는 것을 전제로, **제품 데이터(`PRODUCTS`)만 늘리면 필터·카드·비교표·히어로 인덱스가 자동으로 갱신**되는 구조입니다.
외부 CDN·프레임워크 의존이 없어 카페24 등 어떤 정적 호스팅에도 폴더째 올리면 그대로 동작합니다.

## 구성
- `index.html` — 헤더 · 히어로(브랜드 + 컬렉션 인덱스) · 브랜드 스토리 · 제품 유형 안내 · 전 제품(필터/검색/정렬) · 스펙 비교 · FAQ · 상담 · 푸터 · 제품 상세 모달
- `styles.css` — 디자인 시스템과 반응형 레이아웃 (1920 / 1024 / 720 / 390 대응)
- `script.js` — `PRODUCTS` 데이터, 카드·비교표·인덱스 렌더링, 유형 필터, 검색(제품명·원료), 정렬, 상세 모달, 모바일 메뉴, 스크롤 리빌, Canvas 배경
- `assets/` — 로고, 제품 이미지 4종(500×500), OG 이미지, 파비콘, 셀프호스팅 폰트

## 제품 유형 표기 원칙 (식품표시광고법)
- `category`는 `hff`(건강기능식품) 또는 `general`(일반식품) 중 하나입니다.
- **엽산(올인원 액티브 활성 엽산 800)만 `hff`** 이고, 콜라겐(액상차)·멜라토닌(과채가공품)·글루타치온(음료베이스)은 `general`입니다.
- 일반식품에는 **기능성·효능·신체 부위/증상 개선을 암시하는 문구를 넣지 않습니다.** `foodType`(식품유형)·원재료·내용량·섭취 방법만 표기합니다.
- 건강기능식품의 기능성 내용은 제품 라벨 표기를 따르며, 사이트에는 "라벨 기준" 안내만 둡니다.

## 제품 추가하는 방법
`script.js`의 `PRODUCTS` 배열에 아래 키를 가진 객체를 추가하면 됩니다.

| 키 | 설명 |
| --- | --- |
| `key` | 고유 식별자(카드 앵커·모달 연결) |
| `en` | 영문 라벨 (예: `VITAMIN D`) |
| `name` / `short` | 제품명 / 짧은 이름 |
| `category` | `hff` 또는 `general` |
| `foodType` | 식품유형 (건강기능식품은 `건강기능식품`) |
| `form` | 성상 (정, 액상 스틱 등) |
| `content` / `serving` | 내용량 / 섭취 방법 |
| `store` | 성분 기준 단위 (선택, 예: `1정(500 mg)당`) |
| `ingredients` / `desc` | 원재료·주요 성분 / 소개 문장 |
| `chips` | 카드·비교표에 노출할 성분 목록 |
| `price` | 판매가(원) |
| `accent` / `accentDeep` | 카드 포인트 색상 |
| `img` / `link` | 제품 이미지 경로 / 카페24 상품 URL |

추가 후 `index.html`의 자산 버전 쿼리(`?v=14`)를 올려 주세요. 별도 HTML 수정은 필요 없습니다.

3. 상품 구매 버튼은 현재 `cestlavie4705.cafe24.com`의 실제 상품 페이지로 연결되어 있으므로 그대로 사용 가능
