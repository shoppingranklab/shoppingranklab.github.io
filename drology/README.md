# 닥터올로지 (Dr.Ology) 브랜드 스토어

가정의학과 전문의가 직접 운영하는 브랜드 Dr.Ology의 정적 브랜드 스토어입니다.
제품이 계속 추가되는 것을 전제로, **제품 데이터(`PRODUCTS`)만 늘리면 필터·카드·비교표·히어로 인덱스가 자동으로 갱신**되는 구조입니다.
외부 CDN·프레임워크 의존이 없어 카페24 등 어떤 정적 호스팅에도 폴더째 올리면 그대로 동작합니다.

## 구성
- `index.html` — 헤더 · 히어로(브랜드 + 컬렉션 인덱스) · 브랜드 스토리 · 브랜드 기준(원료/배합/제형) · 전 제품(필터/검색/정렬) · 스펙 비교 · FAQ · 상담 · 푸터 · 제품 상세 모달
- `styles.css` — 디자인 시스템과 반응형 레이아웃 (1920 / 1024 / 900 / 720 / 390 대응)
- `script.js` — `PRODUCTS` 데이터, 카드·비교표·인덱스 렌더링, 제형 필터, 검색(제품명·원료), 정렬, 상세 모달, 모바일 메뉴, 스크롤 리빌, Canvas 배경
- `assets/` — 로고, 제품 이미지 4종(500×500), OG 이미지, 파비콘, 셀프호스팅 폰트

## 톤 원칙
- 메인은 **프리미엄 데일리 브랜드몰** 톤입니다. 식품 유형(건강기능식품/일반식품)을 마케팅 전면에 세우지 않습니다.
- 식품유형은 **상품 상세 모달의 `식품유형` 한 줄과 스펙 비교표의 `식품유형` 행**에만 담백하게 표기합니다.
- 상품 카드·히어로·네비게이션·FAQ·푸터에는 유형 구분이나 유형 개수 프레임을 두지 않습니다.

## 표시광고법 준수 (수정 시 반드시 확인)
- `category`는 `hff`(건강기능식품) 또는 `general`(일반식품) 중 하나입니다.
- **엽산(올인원 액티브 활성 엽산 800)만 `hff`** 이고, 콜라겐(액상차)·멜라토닌(과채가공품)·글루타치온(음료베이스)은 `general`입니다.
- 일반식품 문구에는 **효능·효과는 물론 신체 부위·생리작용·컨디션 변화를 암시하는 표현도 넣지 않습니다.** (예: 피부, 탄력, 주름, 미백, 수면, 숙면, 잠, 피로, 활력, 항산화, 면역, 안티에이징, 디톡스, 붓기, 혈행, 스트레스, 진정, 개선, 회복 등)
- 일반식품은 **원료명·함량·원산지·제형·맛·1일 섭취량과 섭취 방법·원재료 배합 정보**만으로 서술합니다.
- 건강기능식품은 `functionality` 배열에 **식약처 인정 기능성 내용만** 적습니다. (모달 `기능성 내용` 행으로 출력)
- `alt` 텍스트·메타태그·OG 문구도 같은 기준을 적용합니다.

## 제품 추가하는 방법
`script.js`의 `PRODUCTS` 배열에 아래 키를 가진 객체를 추가하면 됩니다.

| 키 | 설명 |
| --- | --- |
| `key` | 고유 식별자(카드 앵커·모달 연결) |
| `en` | 영문 라벨 (예: `VITAMIN D`) |
| `name` / `short` | 제품명 / 짧은 이름 |
| `category` | `hff` 또는 `general` |
| `foodType` | 식품유형 (예: `액상차`, `과채가공품`, `음료베이스`, `건강기능식품`) |
| `formKey` | `stick` 또는 `tablet` — 제형 필터 기준 |
| `form` / `pack` | 성상(액상 스틱·정제) / 카드에 보이는 짧은 규격 |
| `content` / `serving` | 내용량 / 1일 섭취량·방법 |
| `store` | 성분 기준 단위 (선택, 예: `1정(500 mg)당`) |
| `ingredients` / `desc` | 원재료·주요 성분 / 소개 문장 |
| `chips` | 카드·비교표에 노출할 성분·함량 목록 |
| `origins` | 원료 산지 목록 (비교표 `원료 산지` 행) |
| `howto` | 한 줄 섭취 팁 (선택) |
| `functionality` | 건강기능식품 전용 — 식약처 인정 기능성 문구 배열 |
| `price` | 판매가(원) |
| `accent` / `accentDeep` | 카드 포인트 색상 |
| `img` / `link` | 제품 이미지 경로 / 카페24 상품 URL |

추가 후 `index.html`의 자산 버전 쿼리(`?v=15`)를 올려 주세요. 별도 HTML 수정은 필요 없습니다.
