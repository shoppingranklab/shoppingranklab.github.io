# 닥터올로지 (Dr.Ology) 4대 라인업 홈페이지

콜라겐 · 멜라토닌 · 엽산 · 글루타치온 네 라인업을 같은 비중으로 소개하는 정적 홈페이지입니다.
외부 CDN·프레임워크 의존이 없어 카페24 등 어떤 정적 호스팅에도 폴더째 올리면 그대로 동작합니다.

## 구성
- `index.html` — 전체 페이지 (헤더·히어로 4분할 쇼케이스·브랜드 철학·24시간 루틴·맞춤 루틴 진단·라인업·비교 매트릭스·FAQ·문의·푸터)
- `styles.css` — 디자인 시스템과 반응형 레이아웃 (1920 / 1024 / 720 / 390 대응)
- `script.js` — 쇼케이스 자동·수동 전환, 24시간 루틴 시계, 적합도 계산, 상품 모달, 모바일 메뉴, 스크롤 리빌, Canvas 배경
- `assets/` — 로고, 제품 이미지 4종(500×500), OG 이미지, 파비콘, 셀프호스팅 폰트(Pretendard·나눔명조·Cormorant 서브셋)

## 카페24에 반영할 때
1. `index.html`, `styles.css`, `script.js`, `assets/` 를 카페24 디자인 스킨 폴더(예: `/skin/…`)에 업로드
2. 쇼핑몰 메인 설정에서 해당 `index.html`을 메인으로 지정
3. 상품 구매 버튼은 현재 `cestlavie4705.cafe24.com`의 실제 상품 페이지로 연결되어 있으므로 그대로 사용 가능
