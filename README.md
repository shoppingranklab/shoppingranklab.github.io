# 쇼핑순위연구소 공식 홈페이지

2012년부터 플랫폼을 직접 운영해 온 법인 **쇼핑순위연구소**의 원페이지 랜딩 사이트입니다.
정적 HTML/CSS/JS로만 구성되어 있어 별도 백엔드 없이 GitHub Pages에서 바로 동작합니다.

## 구성

| 경로 | 설명 |
| --- | --- |
| `index.html` | 전체 페이지 마크업(히어로·진단 랩·솔루션·정비 전후 비교·채널·프로세스·CTA·푸터·상담 모달) |
| `styles.css` | 디자인 시스템, 반응형 레이아웃, 키프레임 애니메이션 |

| `assets/hero.webp` | 히어로 비주얼 |

| `assets/hero-og.jpg` | SNS 공유 이미지(1200×675) |

## 인터랙션 (v16)

- **히어로 Canvas**: 딥네이비 배경 위 데이터 노드 네트워크. 화면 밖에서는 정지, 모바일은 노드 수 축소, `prefers-reduced-motion`에서는 정적 1프레임.
- **진단 시뮬레이터(`#sim`)**: 카테고리 버튼(패션·리빙·뷰티) 또는 키워드 입력 → `진단 시뮬레이션 실행`. 3축 게이지·종합지수·스파크라인·레이더 꼭짓점·맞춤 점검 포인트가 함께 재계산되며 히어로 리포트 카드와 데이터 섹션 레이더도 같이 갱신됩니다. 모든 수치는 "예시 시뮬레이션" 표기.
- **키워드 마퀴**: 흐르는 배지를 누르면 시뮬레이터로 이동해 해당 키워드로 자동 실행됩니다(마퀴에 마우스를 올리면 정지).
- **4대 솔루션 카드**: `적용 포인트 보기` 아코디언(체크리스트 + 미니 차트).
- **정비 전후 비교(`#compare`)**: 가운데 손잡이를 드래그(마우스·터치)하거나 토글 버튼으로 전환. 처음 화면에 들어올 때 한 번 자동으로 움직여 조작 가능함을 알립니다.
- **상담 모달**: 헤더 `1:1 상담`·모바일 메뉴 버튼에서 열립니다. ESC·바깥 클릭·닫기 버튼으로 닫히고 포커스가 되돌아갑니다.
- **번호 복사**: `010 7612 9292`를 클립보드에 복사하고 토스트로 알립니다(실패 시 전화 안내 문구).
- **Top 버튼**: 스크롤 시 우측 하단에 나타나 맨 위로 이동합니다.

`styles.css`/`script.js`를 수정하면 `index.html`의 `?v=` 값을 함께 올려 캐시를 갱신합니다.
